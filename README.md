# 圣子猫阅读器

**单行轻阅读，也能大屏专注读。支持 Windows 与 Android，本地书库可备份迁移。**

[开始使用](#开始使用) · [功能特色](#功能特色) · [番茄小说与下载边界](#番茄小说与下载边界) · [开发与构建](#开发与构建) · [协议与声明](#协议与声明) · [致谢](ACKNOWLEDGEMENTS.md)

圣子猫阅读器是一款以本地阅读为基础的阅读工具。Windows 独立版提供隐蔽单行／多行窗口和普通大屏两种阅读模式；Android 版采用正常阅读界面。在线功能整合 SoNovel 聚合搜书与独立实现的番茄小说适配，使用前需阅读并确认在线声明。

本项目由独立维护者维护，**不是 SoNovel、番茄小说或其他参考项目的官方客户端**。

## 开始使用

### 选择平台

| 平台 | 当前源码版本 | 定位与获取方式 |
| --- | --- | --- |
| Windows x64 | **0.5.4** | 隐蔽阅读／普通大屏；[桌面说明](independent-reader/README.md) · [源码构建](DESKTOP_BUILD.md) |
| Android 8.0+ | **1.16.1** | 在线小说 / 漫画书架、下载后离线阅读、下载管理、自定义源与在线听书；[手机版说明与构建](mobile-reader/README.md) |

- 下载入口：[本仓库 Releases](https://github.com/fixz232/shengzimao-reader/releases)。请选择对应平台的附件，是否已提供该版本安装包以发布页实际内容为准。
- **源码版本不等于已发布的安装包版本。** Releases 中没有对应附件时，请按上述文档自行构建；GitHub 的 Source code 压缩包不能直接安装。
- Windows 安装版可在「关于」检查更新，下载并校验后需确认才会安装；更新依赖维护者实际发布的桌面更新通道。
- 上游 SoNovel 的命令行、Docker 和安装脚本面向其自身工具，不是本项目桌面版的安装方法。

### 第一次阅读

1. Windows 首次启动显示欢迎阅读框；**双击打开书库，右键打开菜单**。Android 从「书库」开始使用。
2. 导入自己有权使用的文档，在书库中打开；Windows 可选择隐蔽窗口或普通大屏。
3. 使用在线功能时，先读完声明并明确确认，再检索、核对来源、查看目录和下载。搜索成功不保证正文可下载。
4. 定期导出 `.szmbak` 小说备份。备份包含小说正文和阅读数据，分享前请检查内容与个人信息；Android 1.8.0 备份增加设置、漫画目录 / 进度 / 书签与去除凭据字段的源，漫画图片可选；默认不含图片，临时缓存与队列不导出。请保留本地漫画原件。

## 功能特色

### 一份书库，两种桌面阅读方式

Windows 隐蔽模式提供紧凑的单行／多行阅读窗、自动排字、鼠标移出隐藏、透明度、置顶和老板键；普通模式提供大窗口、段落滚动、目录侧栏、主题和全屏。两种模式共享阅读进度和书签，普通模式字号单独保存。

隐蔽模式启动时有约 5 秒定位提示，便于找回阅读框；未选择书籍时保持欢迎内容可见。**隐蔽模式只是窗口显示方式，不保证在截图、录屏或系统监测中不可见。**

### 本地文档集中管理

书库支持搜索、分类或筛选、收藏、置顶、书籍信息编辑、进度保存与书签。阅读时可使用目录导航、主题、字号调整和系统语音朗读，具体操作随平台有所区别。

| 能力 | Windows 独立版 | Android 版 |
| --- | --- | --- |
| 本地导入 | TXT、EPUB、PDF、DOCX、Markdown、HTML | 小说 TXT、EPUB；漫画 CBZ、ZIP、图片 |
| 导出格式 | TXT、EPUB | TXT、EPUB |
| 书库备份 | 导出／恢复 `.szmbak` | 导出／恢复 `.szmbak` |
| 阅读界面 | 隐蔽单行／多行、普通大屏 | 正常全屏阅读、点击翻页与阅读设置 |
| 在线功能 | SoNovel 聚合搜书、番茄小说标签 | 聚合搜书、番茄小说、下载管理、自定义源在线搜漫 |
| 系统语音朗读 | 隐蔽阅读窗中启用，可调语速与音量 | 阅读页启用，可调语速与音调 |

PDF 只提取文档内已有文字，**不含扫描件 OCR**；旧 `.doc` 请先转为 `.docx`。文档转换以文字阅读为主，不保证保留图片、表格、公式、原始分页与复杂排版。两端备份可互相恢复书籍与进度，阅读设置需在本机调整。

### 搜书、目录与增量追更

- **两类在线来源：** SoNovel 聚合搜书与番茄小说在页内分标签展示；番茄支持书名、作者、书籍 ID 和官网详情链接。
- **先核对，再入库：** 展示来源、简介和在线目录；聚合搜书可比较同书的不同来源，目录可按章节名或序号检索。
- **按书名和作者匹配：** 支持多个关键词，区分同名不同作者的作品；不把近似结果当作精确命中。
- **增量更新：** 对支持追更的在线书籍记录目录，核对通过后只追加末尾新增章节，保留阅读进度与书签。
- **异常停止：** 目录变短、重排、旧链接变化或章节下载不完整时停止追加。源站修改旧章节不会自动覆盖本地正文。

Windows 可选每 30 分钟检查追更，默认关闭，仅在程序运行时执行。公开文集备用版本不参加番茄追更；不同平台的在线适配与限制请分别查看平台说明。

### Android 下载管理与漫画

1.3.0 底部为书库、在线搜书、漫库、在线搜漫、设置。在线搜书新增下载管理，统一管理小说与漫画任务，支持进度、取消、重试和历史；进程退出可能中断，需要手动重试，1.8.0 起小说与漫画均复用验证后的断点，支持暂停 / 继续、Wi-Fi、队列提前和前台下载通知。

漫库支持本地 CBZ / ZIP / 图片、收藏与阅读进度；漫画阅读提供条漫、横向及右到左翻页、目录、长图分块解码和缩放。在线搜漫由用户通过 JSON 文件、链接或文本导入声明式 HTML/CSS、简单 JSON 路径规则，不内置真实漫画源或作品，1.8.0 支持受限旧式规则脚本，不读取 JVM / Android / 手机文件，也不绕过登录、付费或验证。格式和限制见 [漫画源说明](mobile-reader/MANGA_SOURCES.md)。

**按用户要求，本轮暂停运行测试，只做编译与构建。** 1.3.0 的新功能及原下载后退出问题尚未完成本轮真机复测，不能把 1.1.2 的历史验证当作本版通过。构建交付范围见 [1.3.0 构建记录](mobile-reader/BUILD-1.3.0.md)。

### 本地保存，主动备份

书库、正文、进度、书签、统计和在线声明确认记录保存在本机，项目不自动上传本地书库，也未提供跨设备自动同步服务。在线声明确认不随备份转移，恢复备份后仍需由当前用户自行确认。

- Windows 默认数据目录：`%APPDATA%/shengzimao-reader-independent`，可从应用内打开。旧版 `%APPDATA%/single-reader` 不会被自动覆盖；只读迁移需主动确认。
- Android 数据保存在应用私有目录，卸载可能清除数据，请先导出备份。
- 在线搜索、封面、详情、下载、检查更新及透明网页等联网功能会访问第三方服务；本地存储不代表联网匿名。详见 [数据与网络说明](NOTICE.md#数据与网络)。

## 番茄小说与下载边界

番茄功能参考的开源项目是 **[zhongbai2333/Tomato-Novel-Downloader](https://github.com/zhongbai2333/Tomato-Novel-Downloader)**，参考版本采用 MIT License。本项目独立实现公开搜索、详情、目录和下载适配，未接入该项目未公开的服务、私有令牌或第三方地址池。

**能搜到书、看到目录，不代表该书的所有章节都能下载。** 登录、付费、锁定、验证码、网页变更、网络故障及不支持的字体编码均可能导致失败；项目不承诺番茄全站、所有版本或整本书持续可下载。

| 平台 | 已实现范围与限制 |
| --- | --- |
| Windows 0.5.4 | 处理已验证的公开网页字体；未知字体或残留缺字时停止，避免导入乱码。遇到受限或不可读正文会提示原因。 |
| Android 1.8.0 | 保留正文校验、并行下载及已知公开网页字体适配；统一在线阅读工具，增加验证断点、漫画长图位置 / 页面书签 / 双页及扩展备份。源配置完整保存，不能运行的源默认停用并显示原因。手机版仍有独立的平台限制。 |

Windows 对《毛泽东选集》提供精确匹配书名、作者与分卷的独立公开文集备用来源：[weiyinfu/MaoZeDongAnthology](https://github.com/weiyinfu/MaoZeDongAnthology)。使用时标明实际来源与版本差异，正文在用户请求时获取，不随安装包预置。**这是另一个版本，不是恢复不可访问或锁定的番茄版正文。** 第二卷公开版为 40 篇正文，不含番茄目录中的版权页和分卷扉页，也不启用番茄追更。

字体翻译数据另来自 [ying-ck/fanqienovel-downloader](https://github.com/ying-ck/fanqienovel-downloader)（AGPL-3.0），与上述 MIT 参考项目不同。来源提交、许可原文与使用范围见 [第三方声明](THIRD_PARTY_NOTICES.md) 和 [桌面来源记录](independent-reader/PROVENANCE.md)。

下载失败时，请保留错误信息并核对版本、来源与章节状态；可在原站确认可读性，或比较其他有权使用的来源。不要公开上传账号凭据或整部作品。真实验证范围见 [桌面 0.5.4 验证记录](independent-reader/VERIFICATION-0.5.4.md)，不代表对全部书籍的保证。
