# 独立版 0.3.0 更新与验证

日期：2026-10-23。修改范围为 independent-reader；旧版应用与真实用户书库未迁移或覆盖。所有测试均使用隔离配置、合成小说、合成站点与合成文档。

## 已完成

- 追更书架：在线入库保存原站目录，支持单本、批量追更和可选每 30 分钟自动检查。默认关闭自动检查。
- 增量更新：只请求新增章节；不重抓旧章，保留原文前缀、进度、书签和阅读统计；保留最近两份旧正文。删章、重排、旧链接变化和缺章会停止追加并显示原因。
- 目录搜索：本地和在线目录支持章节名、序号、多关键词搜索，显示匹配数量，支持继续加载完整目录。
- 搜书详情：结果显示分类、状态、字数、更新、简介等；提供详情及目录入口。来源没有提供的字段明确显示未知。
- 首次在线声明：需读到底并勾选同意，包含 SoNovel 项目、AGPL 许可、版权、网络访问及风险说明。主进程同时检查，接受记录持久化，备份不会代替首次确认。
- 文档：TXT、EPUB、PDF、DOCX、Markdown、HTML 可导入并转换为 TXT / EPUB。PDF 仅提取文字，扫描件无 OCR；加密文件先解锁，DOC 先另存为 DOCX。

## 本轮修复

备份不同 ID 同名文件覆盖、缺失正文无法恢复、空书库设置/当前书未恢复、备份结构与展开大小校验及失败回滚；取消期间导入仍提交；旧任务覆盖新状态、批次与勾选残留；引擎提前过滤搜索结果；链接在联网后才校验、重定向/DNS 内网防护；整文件读取后才采样；worker 无消息退出悬挂；书尾朗读循环、隐藏继续朗读；管理窗跳页使用固定字数；后台刷新打断输入法；发布版本滞后；临时原生库目录共享；不兼容构建环境生成损坏 ASAR。

构建使用 Node.js 24.19.0 LTS，scripts/build.cjs 限制支持的 LTS 版本，并在生成安装包前逐文件验证 ASAR 完整性。Electron 仍为项目现有 33.4.11；公开分发前应按 README 的既有说明单独升级运行时并重新回归。
