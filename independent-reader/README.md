# 圣子猫阅读器 · 独立版

这是新建的桌面工程，不导入或打包旧版 `src`、`dist`、`.electron-vue`、Vue 组件或状态管理实现。旧版目录、安装包和用户书库不改动。

## 实施顺序与验收

1. 独立实现书库、TXT/EPUB 导入、单行阅读窗、进度、书签及设置；验证导入、翻页、保存重启与窗口可见。
2. 只读扫描旧版 JSON 数据，明确确认后复制文本和备份到新配置目录；验证原文件哈希不变、重复迁移不覆盖进度、缺失文件可追踪。
3. 新写 Java 适配器调用 SoNovel 核心 API，不启动 Web 监听端口；主进程管理任务，页面切换不取消；验证适配与取消/失败处理。
4. 审计来源、运行回归和界面测试，再生成独立安装目录；安装标识与旧版不同。

## 数据隔离

独立版默认数据目录为 `%APPDATA%/shengzimao-reader-independent`。旧版 `%APPDATA%/single-reader` 只读；不会自动覆盖、删除或移动。首次迁移需在界面点击并确认；迁移备份只存入新目录。缺失文本保留可见条目，可重新选择原文件修复。

开发启动：`npm start`；测试：`npm test`、`npm run test:ui`。开发阶段允许复用父目录已安装的开发工具和第三方包，不复用父目录的应用源码。发布构建使用本项目依赖和明确列出的资源。首次依赖安装使用 `npm ci`。

## 开源边界

新写桌面代码以 AGPL-3.0-only 提供。SoNovel 单独保留其上游 LICENSE、来源与完整对应源代码。此工程不是原 single-reader 的授权证明，也不声称经过法律意义上的洁净室流程；此前已审查过旧项目，实现来源审计与法律判断需区分。

当前为 0.4.0 本地验证版，不自动发布 GitHub、不替换旧版、不迁移真实数据，除非用户主动操作。开发工具暂复用本机 Electron 33.4.11，正式公开发布前还需升级受支持运行时并重新回归。

## 阅读框默认行为（0.1.2）

单行、双行及更多行默认按实际字体宽度填满窗口，不再被原来的每行 20 字上限提前截断。需要固定字数时，可在“设置 → 阅读”关闭自动排字，原有手动字数仍保留。

正文下划线已取消，底部进度线默认关闭；鼠标移出阅读框隐藏正文与背景，移入恢复，无需先点击获取焦点，管理界面打开也不强制预览。失焦地址伪装默认关闭，保留可选开关。

首次打开旧独立版配置时，这几项阅读默认值会升级一次，不改动书库、正文、进度、书签或其它外观参数；升级后再次自定义的选项会正常保存。验证命令：`npm run test:reader`，同时覆盖新配置和保留每行 20 字的旧配置，合成测试不使用真实书库。

## 0.2.0 新增

**在线搜书**：支持「书名 作者」多关键词（本地按字段权重打分 0–100，结果不丢弃）；搜索结果按书目聚合多个站点，可展开对比来源、最新章节与简介；书源下拉带命中数量；支持勾选批量下载（一次最多 30 本，串行排队、单槽位），进度面板逐条显示排队/下载中/完成/跳过/失败；重复书自动跳过并提示「已在书库」；失败项可一键重试；显示本次搜索耗时。

**阅读**：阅读窗内按 `S` 或右键「朗读当前内容」使用系统语音朗读当前内容，读到结尾自动翻页续读；设置里可调语速与音量（默认关闭）。书库概览新增最近 7 天阅读趋势与连续阅读天数。

**数据**：设置 → 数据与备份可导出单个 `.szmbak` 备份（含索引、进度、书签与全部正文）并在任意配置目录恢复；重复条目跳过、不回退已有进度；可一键打开数据目录。

**界面**：新增 `app/ui/theme.css` 视觉层（设计令牌、卡片化书库、悬浮反馈、对话框、空状态、响应式），默认主题色保持不变以兼容既有对齐断言。窄窗口（560px）无横向溢出。

验证：`npm test`（71 条）、`npm run test:ui`（parity 64 项）、`npm run test:online-ui`（14 项）、`npm run test:reader`（114 项）、`npm run test:packaged`（13 项）、`node scripts/ui-preview.cjs`（逐页截图）。

## 0.3.0 追更、目录与文档转换

在线入库自动记录原站目录并加入追更；书籍菜单可取消追更或检查更新。书库上方可批量检查追更书籍，可选每 30 分钟自动检查（默认关闭，仅程序运行时执行）。更新只抓取目录末尾新增章节，保留阅读进度、书签、统计和旧正文文件。目录变短、重排、旧链接变化、下载缺章时停止追加并显示原因；源站修改旧章节不会自动覆盖。旧版在线条目可尝试用已识别目录核对，无法安全核对时需保留备份后重新入库。

本地与在线目录均可按章节名、序号和多个关键词搜索，按需加载全部目录。搜书结果补充状态、字数、更新时间、简介和详情入口；缺少的字段显示“源站未提供”。详情会读取源站信息和可搜索目录。

首次使用在线功能需滚动读完声明并勾选确认。声明包含 SoNovel 项目地址、AGPL 来源与许可、版权及第三方内容说明；确认记录只保存在本机，备份不会带入确认。主进程同时检查确认状态。

导入与转换支持 TXT、EPUB、PDF、DOCX、Markdown（.md/.markdown）、HTML（.html/.htm），可另存为 TXT 或 EPUB。PDF 使用 Mozilla PDF.js 4.8.69（匹配本项目 Node/Electron 运行时），只提取文字，不渲染或执行文档脚本。扫描件无 OCR，加密 PDF 需先解锁。DOC 请先另存 DOCX。复杂排版、表格与图片不保证原样保留。

修复了备份同名正文覆盖、缺失正文无法修复、空书库设置与当前书恢复、取消导入仍入库、旧任务覆盖新状态、内网地址校验过晚、引擎提前过滤结果、搜索勾选残留、中文输入被后台刷新打断、朗读书尾循环及隐藏不停读、管理窗跳页按固定 20 字计算、文本采样整文件读取，以及文件 worker 无结果退出时等待不结束等问题。备份合并保留已有进度，失败回滚新增文件；增量更新保留最近两份正文文件。

新增验证命令：npm run test:features。测试使用隔离配置与合成文档/站点，不修改真实书库。

## 0.4.0 普通阅读与搜索匹配

- 首次运行默认打开隐蔽单行阅读框，显示「欢迎使用圣子猫阅读器」；双击进入书库，右键打开菜单。未选择书籍时，欢迎内容保持可见。
- 每次启动隐蔽模式，阅读框在上次保存的位置显示约 5 秒定位提示，然后恢复原有隐蔽行为；鼠标移入可立即结束提示开始阅读。提示不更改透明度、阅读进度或书签。
- 书库的「大屏阅读」、书籍菜单或设置中的「普通大屏」可打开最大化的常规阅读窗口；支持段落滚动、目录搜索、字号、明亮/护眼/夜间主题及 F11 全屏。普通与隐蔽模式共用进度和书签，普通字号独立保存。
- 关于页显示实际运行版本、平台、数据目录与 SoNovel 来源说明。
- 阅读窗口置顶在原生样式修改、显示及恢复后重应用；可取消。去掉单行框右下角直角图形，仍支持右下角拖拽缩放。
- 参照 SoNovel SearchResultsHandler 的相关性思路，搜索优先书名与作者，过滤无关条目，默认按匹配度排序；「书名 作者」必须同时命中。跨站合并规范化标点、全半角及作者前缀，仍区分不同作者。近似结果仅在无直接命中时返回，并明确标识。
- 回归入口：npm run test:normal、npm run test:welcome、npm run test:startup、npm run test:online-ui。生产安装包使用 Node.js 24 LTS 构建，并校验 ASAR 全部文件哈希。
