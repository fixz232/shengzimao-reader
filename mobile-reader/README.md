# 圣子猫阅读 · 手机版

Android 版圣子猫阅读器。与桌面版共用的理念是“打开就读”，但手机版**不包含任何隐蔽 / 伪装模式**：版面、交互与配色都按正常阅读设计。

返回 [仓库首页](../README.md)；许可、内容权利、数据与免责说明见 [项目声明](../NOTICE.md)，组件来源见 [手机版第三方说明](THIRD_PARTY_NOTICES.md)。

- 当前源码版本：**1.16.1 / 27**；安装包请查看 [本仓库 Releases](https://github.com/fixz232/shengzimao-reader/releases) 的实际附件，没有附件时按本文自行构建。覆盖升级必须沿用相同发布签名，源码版本不代表对应 APK 已发布。
- 包名：`com.shengzimao.reader.mobile`
- 最低系统：Android 8.0（API 26）；目标 API 36；编译 API 37

2026-10-27 漫画全量抽查：已清点源站页面的 42 个合集，保留不同规则版本并分别记录搜索、目录、图片下载和 Android 解码结果，详见 [逐源检查报告](reports/yck-all-sources-2026-10-27/REPORT.md)。通过仅表示本次作品/章节抽样可解码；无结果、失效域名、访问限制、未适配规则和原站提示图均不视为可读。新版修复逐图请求上下文、Go 旧接口和包子 APP 提示图误判，并包含此前尚未打入正式包的章节、图片线路与缓存恢复修复。上游流程参考与许可说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 功能

### 1.16.1：在线搜书完整性与失败恢复

- 按请求网址、方法、正文参数和请求头识别目录／正文分页，修复同地址 POST 分页漏章、缺少后半章的问题，同时保留真实循环去重与相邻章节边界。
- 在线阅读不再等待整本后台下载。SoNovel 阅读使用独立的引擎类空间与工作目录，避免并行任务修改彼此配置或输出；阅读实例按分组复用，切换或更新规则后重新加载。
- 每次新搜索自动清除旧结果来源筛选，筛选为空时提供“查看全部书源”入口。
- 聚合搜索展示失败书源及具体原因，保留成功结果；支持只重试失败书源，不重新请求成功源，也不修改已保存的搜索范围。

### 1.16.0：在线听书与小说兼容优化

- 听书 → 声音设置 → 在线音色：新增晓晓、晓伊、晓辰、云希、云健、云扬六个独立中文声线；可试听、切换、调速调音，继续保留系统声音和原有调音风格。
- 在线声音通过微软 Read Aloud 消费端接口合成，需要联网，接口可用性可能改变。首次选择需确认：当前朗读句子及下一句预读文本直接发送给微软，音频仅在手机私有缓存短期保存，不整本上传书库。每次最多预读一句，缓存按文本、声线、语速、音高隔离；失败明确提示重试或切回系统声音，不悄悄换成其他声线。
- 对照 Legado 目录及正文流程，补齐多个分页链接的逐页读取、去重与边界检查，修复仅跟随首个分页链接导致目录不全或正文截断；支持目录列表规则的 `+` 前缀。保留原有分页上限、取消、空正文检查和相邻章边界。
- 本版同时纳入发现页、结果卡片、书源选择面板、阅读工具面板、小说／漫画书架及主题对比度的六项界面优化。

### 导航

底部五个入口：**书库 / 在线搜书 / 漫库 / 在线搜漫 / 设置**。小说与漫画阅读时不显示底部导航，返回各自书库。

### 阅读

- 左右三分之一点击翻页，中间区域呼出菜单；长按屏幕放置书签
- 目录（支持章节名 / 序号搜索）与书签抽屉
- 进度滑杆、上一章 / 下一章、页码与章节名页脚
- 五档底色：纸白 / 护眼 / 豆绿 / 夜间 / 纯黑（正文与底色成对定义，保证对比度）
- 字号 12–40、行距 100%–260%、页边距、字体（黑体 / 宋体 / 等宽）、加粗、首行缩进
- 翻页动画：平移 / 覆盖 / 淡入 / 仿真 / 无
- 听书（系统 TTS）：离线和在线小说均可从当前阅读位置开始，支持开始 / 暂停 / 继续 / 停止、语速、定时停止、中文语音设置和自动接续下一页 / 章；长段落按系统上限分片，不丢字。切换基础声线或调音风格时一次应用声线、语速与音高，并从当前句重播；暂停时不自行开播。用法与系统声线限制见 [听书说明](LISTENING_MODE.md)。
- 阅读时保持亮屏、隐藏状态栏

### 书库

- 导入 TXT / EPUB（可多选），TXT 自动识别 UTF-8 / UTF-16 / GB18030
- 网格与列表两种视图、书名 / 作者搜索、在读 / 未读 / 读完筛选、四种排序
- 收藏、置顶、标记读完、编辑书名 / 作者 / 简介、移除
- 导出为 TXT 或 EPUB（EPUB 按识别出的章节分文件并生成目录）
- 首次启动内置一本《欢迎使用圣子猫阅读》，七章读完即可上手

### 在线搜书与追更

- **在线阅读 / 加入书架**：保存入口、目录、原文缓存与阅读位置，优先恢复本机已缓存章节；未缓存章节才联网读取。阅读缓存与主动下载的离线小说文件分开。
- **导入书库 / 下载导入**：加入下载管理，成功后保存正文并转换为可离线阅读的书库条目；转换时保留章节进度。
- 在线阅读页统一阅读菜单，支持当前章、阅读缓存、已下载章节、全书在线四种正文搜索范围，以及听书、定时、笔记、书签、独立排版、正文净化、换源和目录更新。全书在线搜索须主动点击开始，逐章显示结果并可停止，最多显示 300 处。
- 小说预读会依据阅读速度、网络计费状态和可用堆内存调整，最多预读后续 3 章，计费网络最多 1 章；断网或低内存时暂停。退出或进入后台保存章节与原文位置，退出取消未完成预取，已完成的原文缓存保留。
- 阅读缓存默认最多 64 MiB，按最近访问淘汰；读取验证来源和摘要，损坏项回退联网。缓存可能被淘汰或清理，不等于完整离线下载，也不包含在书库备份中。完整离线阅读请使用下载导入。
- 当前书的正文净化使用字面规则：`-包含文字` 删除整段，`旧文字=>新文字` 替换文字，`#` 开头为注释；最多 50 条。不执行脚本或正则，不改动原始正文；书签、搜索跳转仍映射到原文位置。
- 搜索逐源返回即可展示并打开阅读，无需等全部源结束；打开小说会停止剩余搜索并保留已返回结果。换源先验证新目录和正文，再按 URL、章名、章号及附近文字定位；不唯一时明确提示比例回退，失败保留旧源与进度。
- 在线作品下载入库后，按章节 URL 和正文锚点迁移阅读位置、书签与笔记；无法匹配的旧源记录保留在原始在线笔记中，不强行挂到其他章节。
- 原有已下载书籍继续离线阅读，不会在升级后变成在线条目；小说备份会保存在线书架的目录与位置，但不含在线正文，桌面旧版不识别在线模式时请不要直接打开该类条目。

在线能力移植自桌面版：把 SoNovel 引擎预编译成 dex 随 APK 分发，运行时用 `InMemoryDexClassLoader` 加载，适配层是 `engine/src/org/shengzimao/reader/AndroidEngine.java`（桌面版 `ReaderEngine.java` 的安卓版本）。

- 首次使用需滚动读完声明并勾选确认；确认状态只存本机，不进备份
- 按「书名 作者」多关键词搜索；同书多书源聚合，可切换书源、查看详情与在线目录
- 相关性过滤与排序在本地完成（与桌面版 `search-matching.cjs` 同一套打分规则）
- 下载入库支持 TXT / EPUB；批量下载一次最多 30 本，严格串行
- 入库后自动记录原站地址与在线目录清单并加入追更
- 追更只追加新增章节：源站目录变短、旧章节标题或链接变化时停止并保留原文
- `@js:` 书源规则由 Rhino 执行（上游用 Javet，安卓无 V8 原生库）
- 「在线搜书」页面内提供 **聚合搜书 / 番茄小说 / 下载管理** 三个标签
- 聚合搜书支持 **分组 1–5**：首次默认分组 1 使用内置规则；分组 2–5 可混合导入 SoNovel 与阅读／Legado 文字小说书源。支持文件、JSON 链接、粘贴，文件／链接最多 5000 条、32 MiB。搜索、目录、正文、缓存和断点下载按组及原书源隔离；完成的源逐个返回结果。登录、WebView 和任意 Java API 等规则尚非完整兼容，详细用法与限制见 [书源分组说明](NOVEL_SOURCE_GROUPS.md)。此功能从 1.15.0 起打包，旧 1.14.0 APK 不包含此更新。
- 番茄页同步桌面版公开搜索接口，支持书名、作者、书籍 ID 与官网链接；可看详情、目录、打开官网
- 番茄公开且可读的正文可下载入库并追更，支持与桌面版相同的已知公开网页字体字符映射；未知字体、缺字、登录、付费或验证要求会停止，不保证目录中所有章节都能下载
- 单本下载采用设置中的 1–8 路并发（默认 4），按原目录顺序保存；聚合下载遵守书源配置的更低并发和请求间隔，番茄各 worker 首次请求错开启动；取消或正文缺失时整次任务失败，不把目录或只有标题的章节入库
- 番茄功能独立于 SoNovel，引擎加载失败不影响番茄搜索；错误信息与重新搜索入口会直接显示
- 搜索框支持键盘搜索键，历史关键词在窄屏换行，运行任务可取消

旧版如果已入库“只有目录”的空书，请先备份，再从书库移除该空书后重新下载。相同在线 URL 的已有书按原逻辑去重，升级不会自动覆盖用户正文。

### 下载管理

- 小说与漫画共用持久化任务列表，显示排队、章数进度、耗时、完成及失败原因；可按状态筛选、取消、重试、清理历史、打开阅读
- 多本串行，单本按源限制并发；活动任务去重，一批最多 30 本，活动队列上限 100 个、记录上限 300 条
- 用户主动下载以前台 dataSync 服务和通知保持运行；支持暂停、继续、提前排序和新任务仅 Wi-Fi。系统结束进程后显示中断，由用户主动继续，不承诺系统无限期保活
- 小说复用 URL / 章节名和 SHA-256 验证的章节断点，漫画复用已保存图片；损坏项重新获取。成功入库清除小说工作目录；清理任务记录不删除已入库内容

### 漫库与在线搜漫

- 1.11.0：链接导入显示连接、兼容重试和解析阶段，可停止或重试；连接重置、响应中断及超时最多安全兼容重试一次，保留证书和主机名校验。源搜索与图片 GET 也复用安全兼容连接；POST 不额外重放。
- 修复部分旧式漫源的对象型目录、组合选择器、JSON 路径、变量和图片处理接口兼容问题；脚本计算时限不再误计网络等待。分页返回 `0` 不再跳到无关页面，已知包子公开章节与跳转入口读取完整正文图片列表。手机实际导入的 100 条源逐源结果见 `reports/phone-manga-sources-2026-10-27/REPORT.md`；抽样通过不代表整站所有作品可读，外站、网络与未适配规则仍可能不可用。
- 这 100 条配置中 78 条含加密规则，共 156 个字段，逐项核对独立解封结果；规则解封与正文图片下载/解码分开验证。补齐旧式 `$function getImgList` 回调、JsEngine 网络别名、列表 `toArray`、Jsoup Referer 和倒数选择器；逐页解析的章节回调最多 128 次请求，普通字段脚本仍最多 12 次，网络错误保留原始原因。
- 2026-10-27 最终验证：279 项单元测试和五套 R8 真机回归通过；100 条实际配置中 18 条抽样正文图片下载、Android 解码通过，其余网络、访问、规则或样本问题逐项记录。正式 APK 的版本、签名和校验值见 `reports/ycy-reader-2026-10-26/package-check.json`；抽样通过不代表整站所有作品可读。
- 图片请求保留章节来源页与旧式规则产生的请求头，随章节地址持久化，更新目录和重开阅读后恢复；失败图片可以单独重试或刷新章节链接。直接开读的目录失败进入重试与查找替代版本页面。
- 漫画阅读新增自动条漫滚动、定时左右翻页、章节/页码/时间/电量状态条，以及目录正倒序、仅缓存筛选、当前章定位、原始序号跳转。触摸、缩放、工具面板和切入后台会暂停自动阅读，重开不会自动启动。
- 参照 Mihon 和 Venera 补齐图片实际解码状态：尺寸解析不再代表已经显示，自动阅读等待可见图块解码成功；解码失败进入图片恢复流程。显示图片连接、下载百分比、源解码和文件验证阶段；旧的无效缓存自动重新请求，刷新后位图缓存按文件版本区分。
- 导入可区分 Venera JavaScript/仓库索引和 Mihon APK/扩展仓库元信息，明确提示运行时不兼容；这些格式不能仅靠转换名称、网址变成异次元规则。参照范围与真实验证见 [双项目对照报告](reports/mihon-venera-pipeline-2026-10-27/REPORT.md)。
- 对照本地异次元 2.4.2 的交互及 Venera 的分层流程独立实现，参照范围和实测限制见 [本轮说明](reports/ycy-reader-2026-10-26/REPORT.md)。Venera 使用另一套 JavaScript 源 API，不能把其脚本或索引当作异次元 JSON 直接导入；本轮没有整体移植其运行时。

- **在线阅读 / 加入书架**：持久保存目录、已解析的章节图片地址及阅读位置，重开优先复用本机图片；地址失效时可在阅读菜单刷新本章图片地址。图片缓存可清理，完整离线观看请主动下载。

- 漫库支持「在线 / 离线」筛选；主动下载与临时缓存分开，清理临时缓存不影响完整下载章节。本地导入不受缓存清理影响。可以明确删除某作品的已下载图片，保留目录、进度和书签。
- 搜索结果尚未加载目录时，加入书架或下载导入会先获取目录；目录为空或网络失败显示错误，不在主线程抛出异常。批量下载会先逐本入架再排队。

- 漫库：导入 CBZ / ZIP / 多张图片，自然排序、搜索、在读 / 未读 / 收藏 / 离线 / 已缓存筛选、改名及移除；暂不支持 CBR / RAR
- 漫库顶部提供「继续阅读」横向卡片；网格卡片显示章进度角标；长按卡片进入多选，可批量缓存与收藏
- 缓存管理：显示在线图片缓存占用与文件数，支持全部清理，或按容量上限淘汰最久未用的图片
- 漫画阅读：条漫、横向、日漫右到左三种方向；默认沉浸式，单击中央呼出工具栏，4 秒后自动隐藏
- 漫画阅读设置与小说阅读设置分开保存：阅读方向、图片缩放策略（适应宽度 / 高度 / 整页 / 原图）、阅读底色（纯黑 / 深灰 / 浅灰 / 纸白）、图片间距、页面边距、亮度、保持亮屏、双击放大倍数、缩放锁定平移、音量键翻页、到达章末自动接下一章、翻页位置提示
- 长图分块解码，整页所有块共享同一缩放状态，放大时不会错位；双指围绕手指落点缩放，平移限制在图片边界内
- 目录支持章节名搜索、当前章定位和阅读页内更新；更新保留旧章节缓存和位置，失败保留旧目录。支持追更开关、新增章节提示、检查时间和直接阅读新增章节；自动检查只在应用运行且启用自动追更时执行。
- 阅读时按翻页速度、网络和内存调整后续图片及下一章开头图片预取，可设置仅在非计费网络预取；低内存或断网时暂停。离开阅读和进入后台保存章节、图片引用及长图内部位置。
- 智能裁白边可按书开启，保守检测左右对称白边并保留安全边距，手动裁边继续可用。双页模式支持智能跨页识别：封面和横向跨页独立显示，按原图页号保存进度。
- 阅读页显示章节地址、图片读取和失败状态，提供失败图片重试、刷新本章地址、更新目录与换源。漫画换源先验证新目录和图片地址，按章名/话数及页面比例恢复；旧源的页面书签不会自动对应到新图片。
- 在线搜漫：可同时查询所有启用源（「全部源」）并合并结果、按相关度排序与过滤；保留最近搜索关键词
- 搜索结果标记「已在漫库」，支持勾选批量加入漫库并缓存；长按结果可直接加入漫库
- 自定义漫画源：从 JSON 文件、链接、文本导入；预览确认、同 ID 更新、启停、删除和导出
- 漫画源支持「编辑」独立的编辑页，源 ID 只读锁定（与漫库和图片缓存关联）；每个源可「测试」搜索 / 目录 / 图片三段规则并给出具体失败环节
- 支持声明式 HTML/CSS 选择器或简单 JSON 路径，搜索翻页、详情、目录、在线图片与离线缓存；图片缓存全局最多 3 路并发，已缓存章节可离线阅读
- 不内置真实漫画站点或作品；支持受限 Rhino 旧式规则脚本，不能访问 JVM、Android 或手机文件；未知加密版本、损坏及不支持的规则保留配置并标记，不兼容 Mihon / Tachiyomi APK 扩展。完整协议、可修改示例及限制见 [MANGA_SOURCES.md](MANGA_SOURCES.md)

### 1.4.1（本地构建）

在线下载提速

- 番茄小说下载改为**滑动窗口并发**：始终维持 N 个章节请求在飞，任一章节返回后立即补发下一章；不再「每 4 章一批、批间等待最慢的一章」
- 去掉每章启动前的 120ms 串行等待。旧实现下 4 路并发实际吞吐被压到约 8 章/秒，且网络抖动时会退化成近乎串行
- 放大约束到并发路数的 OkHttp 连接池（每主机 8、总 16），减少反复建连的开销
- 聚合搜书引擎 `crawl.concurrency` 由 4 提到 8；`config.ini` 缓存戳升级到 v13 以确保新配置下发
- 设置页新增「同时下载章节数」（1–8 路，默认 4）。调高更快，但更容易被源站限速
- 下载进度回调从每章刷新改为 250ms 节流，避免进度刷新反过来拖慢下载；进度文案显示实时「章/秒」
