## 环境与验证边界

- Windows / PowerShell；连接的 Android 16 / API 36 手机，运行当前源码的真实 `MangaEngine`、旧式规则运行时及 Android 原生图片解码器。
- 测试前两轮各自从手机成功取得源目录 HTTP 200，作为基础联网对照；目录第一页 ID 与现有快照一致。本次范围仍为已保存的 622 份快照，不声称重新核验整个目录的实时总量。
- 每轮最多 8 份配置并发，同一源基础域名串行；单请求诊断预算 8 秒、单源 35 秒、单响应 4 MiB。超过预算的结果不代表生产超时设定或站点永久不可用。
- 搜索关键词及首章选择规则见 JSON 元数据；每源最多试两个关键词。初筛只验证首图，随后对全部 9 份候选抽查首章第 0、1、中间、末尾图片。不是整章逐图或整书验证，也没有逐个打开 Compose 阅读界面。
- 原本停用的源仅在独立诊断副本中临时允许测试。正式书库、已导入源和启停状态保持原状；测试缓存位于独立临时目录，未下载整本作品或保存图片到正式漫库。
- 诊断代码位于忽略目录 `.tools/manga-live-audit/`，通过显式初始化脚本才加入测试 DEX，不进入普通源码构建或 release 源集。本轮未修改生产代码、未打包 APK。
- 生产代码 SHA-256 与上一轮已验证版本一致。原始请求记录只保留阶段、站点、路径、状态及类型，不记录响应正文、Cookie 或请求令牌；最终报告已省略异常中的手机地址。
