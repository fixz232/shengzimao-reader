## 本轮改了什么

### 一、整体视觉重构为「玻璃」体系

新增 `ui/theme/LiquidGlass.kt`（材质与配色）与 `ui/theme/RealGlass.kt`（真实光学实现）：

- **配色**：六套 —— 极光 / 蜜桃 / 薄荷 / 暮霞 / 星夜 / 透明。
  每套都有浅色与深色两版，强调色会注入 Material 色板，
  所以 Switch、Slider、Chip、分段按钮会跟着一起换色。
- **质感**：液态玻璃 / 拟态玻璃 / 磨砂玻璃，三者与配色自由组合。
- **深浅**：跟随系统 / 白色（浅色）/ 深色。白色是默认观感。

### 二、把「假玻璃」换成真玻璃

旧实现只是「半透明底色 + 一层矩形径向高光」，看着像玻璃但不是：

| 旧问题 | 现在的做法 |
| --- | --- |
| 无背景模糊，只是透出 | **液态**：按玻璃在窗口里的真实位置，把背后的极光重新取样、`BlurMaskFilter` 软化成磨砂后绘入玻璃 —— 玻璃里显示的是「真正在它背后的颜色」 |
| 描边整圈同色，不像玻璃 | 沿对角方向的渐变描边：迎光的左上最亮、右下几乎无光 |
| 只有一层高光 | 追加**内壁折射带**（贴内边缘的第二道细亮边）+ **斜向光泽带**（表面反光） |
| 拟态只有内部高光，浮不起来 | **拟态**：左上投亮投影 + 右下投暗投影，都用真实高斯柔化；再加左上内高光 / 右下内阴影 |
| 拟态还带 1px 描边，退回扁平卡片 | 拟态不再有描边，层次全部由光影表达 |

### 三、布局与页面修复

- 底部导航改为**悬浮玻璃胶囊**（左右 18dp、避让手势条），选中项是彩色渐变块。
- `发现` 页顶部那条白带：根因是 `SecondaryTabRow` 自带不透明 surface 与一个空 `TopAppBar`；
  已换成透明玻璃分页条 + 一行右对齐的动作胶囊。
- `书架` 页多出的一块空白：内层 `Scaffold` 又套了一层系统栏 inset；已通过
  `contentWindowInsets = WindowInsets(0,0,0,0)` 消除。
- 极光色团从「椭圆尺寸 + 长轴半径」改为「圆形色团 + 长边半径」，消除了屏幕中部的灰雾。
- 设置页「翻页方式 / 页码样式」由固定 `Row` 改为 `FlowRow`，
  修复窄屏上第 4 个选项被挤成竖排单字的问题。
