# 聚合搜书的书源分组

更新日期：2026-10-29。本文功能从 1.15.0 起打包；旧 1.14.0 听书版 APK 不包含本次新增功能。

## 使用方法

1. 打开「在线搜书 → 聚合搜书」。
2. 首次进入默认选中「分组 1」，使用应用内置的 SoNovel 书源，不能往这组导入用户规则。
3. 切换到「分组 2」「分组 3」「分组 4」或「分组 5」，点击「导入书源到分组 X」。
4. 选择 JSON 文件、输入返回规则 JSON 的 HTTP(S) 链接，或直接粘贴规则。
5. 查看新增、更新、跳过和本组总数，再输入书名搜索。每次只搜索当前分组；当前组为空或没有启用搜索的源时，先导入或切回分组 1。

五组规则分开保存。切换分组会清空上一组结果、详情和勾选项，结果筛选恢复为全部来源；搜索仍按完成的源逐步显示。正在搜索、下载占用引擎或导入时，分组切换暂时禁用。重新打开应用会记住上次所选分组。

## 导入格式

此入口支持 **SoNovel 和阅读／Legado 的文字小说书源 JSON**，可在同组混合导入。支持：

- 单个书源对象。
- 多个书源组成的 JSON 数组。
- `{"rules": [...]}` 包装。

SoNovel 规则至少包含 `name`、HTTP(S) 的 `url`、`toc.item` 和 `chapter.content`。启用搜索时还需有 `search.url`、`search.method`（GET 或 POST）、`search.result` 和 `search.bookName`。`book` 未提供时补空对象，由引擎沿用默认元信息规则。省略的正文过滤字段和段落分隔符会补齐默认值。

阅读／Legado 新格式保留 `bookSourceName`、HTTP(S) 的 `bookSourceUrl`、`searchUrl`、`ruleSearch`、`ruleBookInfo`、`ruleToc`、`ruleContent` 等原始规则，交由独立的小说兼容引擎执行。支持源网址后的 `##标签`，相同域名不同标签保留为独立书源。文字源 `bookSourceType` 为 0；目录需有 `chapterList/chapterName`，正文需有 `content`。多章目录需有有效 `chapterUrl`；单条目录省略此字段时使用当前页面作为正文地址。搜索规则需包含 `bookList/name/bookUrl`。旧格式的 `ruleSearchUrl`、`ruleChapterList`、`ruleContentUrl`、`ruleBookContent` 等也有对应入口。

文件／链接导入每次最多 **5000 条、32 MiB**，每组保存总量同样有此限制。粘贴框另有长度限制，大合集请用文件或链接。混合输入中无效条目会计入「跳过」并列出部分原因，其余有效条目保存；全部无效时保留旧规则。数组内同站点重复项采用最后一条；再次导入更新同组对应站点，未提及的原书源保留。

对于源仓库网站，请使用详情页里的 **JSON 下载链接或下载后的 JSON 文件**，列表页／详情页的 HTML 地址不是规则文件。音频、视频、漫画源不作为文字小说源导入；JSON5 也不支持。

## 阅读兼容范围

- 搜索、详情、目录和正文规则按原格式执行，不把 Legado 选择器转换后交给 SoNovel 引擎。
- 支持默认选择器（含属性、序号）、CSS、XPath、JSONPath、正则替换、受限 JavaScript、内联 `jsLib`、`@put/@get` 与常用 `java` 辅助方法。
- 支持 `{{key}}/{{page}}` 搜索模板、GET／POST、表单／JSON 请求正文、请求头、字符集、重定向及按源隔离的临时 Cookie 会话。
- 支持独立目录页、目录分页、正文分页、段落换行、`replaceRegex` 正文净化和章节变量。正文分页会过滤相邻章及返回目录的链接；若已有正文，后续页的正文容器为空且明确返回目录，按分页结束处理。首页正文为空仍报错。
- 支持在线书架、正文缓存、并发下载、失败后保留已下载章节、再次下载复用已保存章节及追更。完成的源逐个显示结果，可停止搜索后直接阅读。

**这不是完整的阅读／Legado 应用运行环境。** 当前没有登录／验证码交互页，不执行任意 Java 类、Android API、文件访问或 WebView 网页脚本。依赖这些能力、未实现的辅助方法、外部脚本加载或特殊平台接口的源，可能需要独立适配。导入成功只说明格式校验通过，不代表源站的搜索、目录、正文都可用。网络失效、付费权限和原站限制也不会因格式兼容而消失。

请只导入可信规则。书源中的脚本按现有聚合引擎执行方式处理。外部站点的可用性、登录要求或内容授权并不会因导入成功而改变。

## 阅读、下载与数据

- 搜索结果、在线书架和下载任务记录规则所属组，以及阅读书源的稳定标识。即使切换分组，旧书的目录、正文、追更和下载仍使用原组与原源。
- 同网址在不同组／不同阅读书源的正文缓存、书架去重、下载任务去重及下载工作目录相互隔离。
- 旧书和旧下载任务默认属于分组 1，旧正文缓存键保持不变。番茄小说仍使用独立页与原有流程。
- 分组选择和用户书源保存在应用私有目录 `novel-source-groups/`，不写入内置规则目录，应用更新释放内置资源时不会覆盖用户组。
- 书库备份保存书籍所属分组，但当前不包含自定义组规则文件。换设备或清除应用数据后，请把原规则 JSON 重新导入相同编号的组；建议保留原始规则文件。正文缓存也不属于书库备份。
