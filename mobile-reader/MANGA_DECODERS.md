# 漫画图片解密器适配记录

日期：2026-10-26。基于 Android 1.10.1 的当前开发源码；此项更新尚未生成新的发布 APK。

## 目录审计与覆盖范围

审计对象为用户指定的 yckceo 异次元单源目录 `/yiciyuan/tuyuan/index.html`。本次读取 7 页、622 条公开源配置；其中 25 条填写了 `ruleBookContentDecoder`，去重后为 7 份脚本、6 类图片算法。统计是当日配置快照，目录后续更新的脚本需要重新核对。

| 算法 | 源配置数量 | 实现 |
| --- | ---: | --- |
| 漫蛙 | 13 | AES/CBC/PKCS5Padding，按原脚本的 UTF-8 字面密钥和 IV 处理 |
| JM | 7 | MD5 末位字符 ASCII 决定分片数；按作品 ID 分段，倒序还原行条带及余数；两份 let/var 脚本均识别 |
| 哔咔 bikahub | 1 | AES/CBC/PKCS5Padding；密钥和 IV 按 UTF-8 字符串处理，不当作十六进制 |
| 包子尺寸规则 | 1 | 使用图片 URL 的 `#宽x高` 尺寸；保留原脚本的比例容差和 1×1 直通逻辑 |
| 香香腐宅 | 1 | 列条带倒序；非整除尺寸使用完整整数边界，避免丢列；其 H006 目录规则也已适配 |
| 果果 / 污污 | 2 | 数字图片文件名的 MD5 决定行条带数，还原余数 |

当前 7 份图片脚本均有原生实现，25 条解密源均可通过导入时的兼容检查。另已解出目录中 39 条配置的全部 71 个 H 加密字段，并与用户手机原版异次元 2.4.2 逐字段核对；包括香香腐宅的 H006 目录规则。H 配置解封与图片字节解密属于两层，完整实现、改域名修复和验证边界见 [加密规则适配记录](MANGA_PRIVATE_RULES.md)。

此覆盖统计不等于 622 个站点均可阅读。站点有效性、搜索/目录脚本的其他能力、登录或访问限制、失效域名、过期图片链接等仍需要分别验证。本次未逐站下载漫画作品。

逐项转换审计得到 618 条结构可转换配置，另 4 条地址格式无效并明确报告原因；部分投稿使用同名同域的重复 ID，导入时仍按既有规则去重。无效地址不再以未捕获的 URI 异常中断其余源处理。

## 下载及兼容处理

- 解密发生在下载临时文件与图片有效性检查之间。解密失败不会写入成功缓存或标记章节下载完成。
- 只识别审计过的脚本指纹，原生执行限定的 AES、条带和尺寸算法；不开放源脚本的 `JavaImporter`、`Packages` 或任意 JVM / Android 类访问。未知或改写过的解密脚本保留配置并明确提示尚未适配。
- 哔咔的 `@Header:{...}<js>...</js>` 前置请求头不再截断图片提取脚本。前置和后置声明、大小写、JSON 内转义及 `{{...}}` 表达式均有回归；`host` / `thisPage` 请求头变量按当前页面展开。原有请求头白名单继续生效。
- 普通图片不会被重复执行 AES。封面跳过正文条带/尺寸还原，且与正文分开缓存，避免数字文件名封面被误处理。
- 解密版本及脚本指纹进入缓存键，避免继续复用旧版未还原的有效拼图。原始旧文件不自动删除；需要重新联网读取这些页面。主动删除下载时一并清理对应旧缓存，并保留其他作品共用的图片。
- 已解密缓存仍可受保护下载、清理临时缓存、备份和恢复。源停用或删除后，已下载的新解密图片仍可离线读取；新备份记录图片解密版本，旧备份不会被误认为已经还原。
- 变换串行执行并使用原生分区解码控制内存。需要变换的输入和输出各不超过 1200 万像素，下载与还原后文件均有 24 MB 上限；超限、非法尺寸、非法条带数会给出错误并保留失败状态。

## 更新已有源

重新从原始旧式 JSON 导入对应源，同 ID 更新会保留漫库。新导入的已支持解密源不再因“需要专用图片解密器”或已支持的 H 加密封装一律停用。以前保存的停用源会更新兼容提示，但不会擅自改变启停状态；可以在源管理中核实后启用。未知加密版本和损坏配置仍明确停用。

## 验证方式

图片解密阶段单元测试记录：189 项，0 失败、0 错误、0 跳过。Android 原生探针全部通过，末尾输出 `DECODER_NATIVE_ALL_OK`；该阶段汇总保存在 `.tools/decoder-verification.json`。本轮新增的 H 格式测试与原版对照记录见 [加密规则适配记录](MANGA_PRIVATE_RULES.md)。

- JVM 回归使用公开规则样本与原创合成数据，覆盖全部 25 条解密配置、7 个指纹、6 类算法、MD5/ID 边界、行列像素覆盖、AES 二进制和错误输入、前后置请求头、缓存隔离及共享下载清理。
- Android 原生验证通过独立 `/data/local/tmp/szm-decoder-probe-*` 目录运行生产解密类，使用原创 PNG 与本地 HTTP 服务。没有安装或覆盖正式版，也没有访问正式书库。
- 原生结果包含两类 AES、三类条带逐像素核对、包子尺寸、封面直通、重复解密防护、8 个并发调用的同图去重、损坏密文拒绝、临时文件清理、离线备份恢复，以及停用/删除源后离线读取。
- 原生验证入口：`app/src/qa/java/com/shengzimao/reader/mobile/MangaDecoderNativeProbe.kt`；日志：`.tools/decoder-native-probe.log`。该入口仅属于 QA 源集，不进入 release 源集。
- 目录抓取和审计原件存于 `.tools/yck-decoder-audit/`；默认测试使用固定样本，不依赖网站联网响应。完整目录转换审计由 `.tools/qa-decoders.init.gradle` 开启。

Release Kotlin 编译及 `lintRelease` 检查通过。单元测试、完整目录审计和最新 Debug DEX 构建均通过，Android 原生探针已针对最终 DEX 复测。Debug 全量 lint 另有既存的 4 处 QA `ViewModelStore.put` 的 `RestrictedApi` 报错，不属于图片解密生产代码；没有屏蔽这类检查。
