# 手机版 1.7.0 阅读器评审与拓展清单

评审日期：2026-10-25。对象为当前 Android 源码 versionName 1.7.0 / versionCode 12。

本文中的“动漫”按项目当前的漫画图文阅读功能评估，不包含动画视频播放器。下面是评审与建议，尚未实施为新版本功能。

## 结论

优先完善阅读操作、进度和离线保存的可靠性，再补在线小说与离线小说的体验差距。漫画的在线 / 离线已经共用阅读页面，适合继续完善同一套工具；小说则应该统一阅读外壳和常用工具，保留联网取章与本地取文的不同数据路径。

保留目前明确的产品约定：在线书架保存入口、目录和进度，重新打开时需要联网；下载导入完成后才作为离线作品使用。会话内的预取不等于完成离线下载。

## 应先核验的功能问题

### P1：漫画跳页的状态与视口可能脱节

代码发现：进度滑杆与音量键更新 `currentPage`，而实际的 `list.scrollToItem` / `pager.scrollToPage` 位于以 `pages、chapterIndex、settings.mode` 为键的 effect 中，没有随着 `currentPage` 的变化执行跳转。另一个监听器又把视口页码写回 `currentPage`。因此存在数字改变、画面未移动，随后数字又恢复的逻辑风险。

建议：建立明确的 `seekToPage` 操作，由用户跳转触发滚动；视口监听仅记录实际位置。滑杆拖动先预览，松手执行跳转，避免连续拖动发起大量互相取消的动画。

验收：在条漫 / 横向 / 日漫三种模式各测试拖动至 25%、75%、首尾页，以及音量键前后翻页；画面、页码和保存位置必须一致。另测缩放状态下的手势冲突。

证据：[MangaReaderScreen.kt:133](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/ui/MangaReaderScreen.kt:133>)、[视口恢复与监听:148](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/ui/MangaReaderScreen.kt:148>)、[滑杆回调:280](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/ui/MangaReaderScreen.kt:280>)。状态：静态代码发现，尚未新增真机复现。

### P1：离线小说的进度预览没有使用目标页

`previewTitle` 计算了目标页 `target`，随后仍使用 `book.position` 查询章节。这会让拖动时的“跳到：章节名”依赖旧阅读位置。

建议：将目标页映射到目标正文偏移，再查该位置的章节；预览百分比同步使用拖动位置。

验收：跨越至少三个章节拖动，预览应随目标章节改变，松手后的实际位置应与预览一致。

证据：[ReaderBars.kt:181](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/ui/ReaderBars.kt:181>)。状态：代码中已确认目标值未用于章节预览，界面影响仍需专项回归。

## 阅读体验的优先改进

### P1：统一在线 / 离线小说的工具入口

当前离线小说已有听书、书签、全文搜索、划线和笔记；在线页主要是目录、下载、前后章与重试。在线页复用了字体等设置，却没有同等直接的设置入口，而且上下栏常驻。

建议共用轻触呼出菜单，顶栏保留返回、书名 / 章节、更多；底栏保留目录、进度、听书、设置。在线模式额外提供源信息与下载，错误时显露重试；书签、搜索等放到更多或底部面板。先补当前章搜索，完整在线全文搜索另行设计，避免为搜索隐式下载整本书。

在线与离线的工具能力可以一致，数据来源和下载边界仍保持清楚。在线注释应以书籍入口、章节标识和文字锚点定位，不能直接复用离线全文字符偏移。

证据：[OnlineReaderScreen.kt:83](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/ui/OnlineReaderScreen.kt:83>)、[ReaderBars.kt:69](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/ui/ReaderBars.kt:69>)、[ReaderOverlays.kt](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/ui/ReaderOverlays.kt>)。

### P1：保存“屏幕内的位置”，而非只保存章节 / 图片编号

在线小说当前保存首个可见列表项编号，没有保存该项内部滚动偏移；一段正文可被分成最长 1200 字符的块。漫画当前保存章节和图片页码，恢复条漫时回到图片的首个 tile。长段落或长图读到中间退出，恢复位置可能明显靠前。

建议：小说记录稳定的文字锚点及段内位置；漫画记录章节、图片稳定标识、图内纵向比例。字体、图片宽度或屏幕尺寸变化时，用锚点重定位，避免直接套用旧像素偏移。

验收：在长段落 / 长图中间退出再进入；旋转屏幕、修改字号 / 缩放策略后，仍恢复到相近内容，不跳回段落或图片顶部。

证据：[OnlineReaderScreen.kt:48](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/ui/OnlineReaderScreen.kt:48>)、[MangaReaderScreen.kt:148](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/ui/MangaReaderScreen.kt:148>)。

### P1：把“下载保存”与“临时缓存”分开

当前线上漫画图片和完整下载的漫画图片都经 `cachedImage` 保存在共享 `images` 目录。清理 / 裁剪缓存会撤销缺页章节的已下载标记并恢复联网状态；这是当前实现的行为，但与“下载导入后长期离线”的直觉存在冲突。

建议分成两种存储策略：临时阅读缓存可以按容量自动淘汰；主动下载的章节默认受保护，只在用户明确删除该作品下载内容时移除。存储页分别显示两类占用，清理前显示影响作品数。

验收：整部漫画下载后断网可读；清理临时缓存后仍可读；只有明确删除已下载内容后才失去离线可用性。本地 CBZ / 图片导入也不受缓存清理影响。

证据：[MangaStore.kt:15](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/data/MangaStore.kt:15>)、[清理逻辑:109](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/data/MangaStore.kt:109>)、[下载逻辑:415](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/ui/MangaController.kt:415>)。

### P2：在线阅读的预取与失败恢复

- 小说增加会话内下一章预取和取消机制；离开作品后停止无关预取，并限制内存中的章数。重新打开在线作品仍遵守联网读取的产品约定。
- 漫画已有临近章末预取；进一步按 Wi-Fi / 移动数据及当前阅读速度控制张数，当前页请求优先于下一章预取和后台下载。
- 加载下一章时显示明确章名；重新加载失败时保留仍有效的正文或图片，不把可读界面整体清空。
- 图片级重试保留成功页，提供“重试失败图片”；明确区分无网络、源站无正文 / 图片、规则失效等情况。

## 下载与数据能力拓展

当前队列已有记录持久化、重试、取消和失败状态；退出后的活动任务会标为中断。它没有真正的暂停状态，也不是退出后继续执行的系统后台任务。

建议按以下次序扩展：

1. **章节 / 图片级恢复**：持久化已验证的完成项；失败或进程重启后复用这些项。小说按章节恢复，漫画按图片恢复；章节目录变化时重新校验，防止拼错书。
2. **可靠的后台传输**：通知栏显示进度与取消；依据系统版本、任务时长和用户是否主动发起选择 Android 支持的调度方式，保留可中断和重试的设计。
3. **下载控制**：暂停 / 继续、仅 Wi-Fi、队列排序、剩余空间预检、失败章节重试、漫画未读章节 / 区间下载。小说已有章节区间选择，应复用现有逻辑。
4. **源兼容性展示**：导入预览和源测试已经存在；扩展为带最后检测时间的搜索 / 目录 / 图片分项状态，并保留跳过原因。不要把结构转换成功当成站点可读。
5. **备份扩展**：现有小说备份之外，增加阅读设置、漫画目录 / 位置 / 书签、漫画源配置的可选导出；大体积图片另设选项并估算大小。敏感凭据不应默认随源配置导出。

证据：[DownloadQueue.kt:65](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/data/DownloadQueue.kt:65>)、[中断恢复:101](<E:/圣子猫单行阅读器/mobile-reader/app/src/main/java/com/shengzimao/reader/mobile/data/DownloadQueue.kt:101>)、[现有版本功能与限制](<E:/圣子猫单行阅读器/mobile-reader/README.md>)。后台方案及触控规范另核对了 Android Developers《Data transfer background task options》《API defaults》；具体实现仍需覆盖项目最低 API 26。

## 建议排期

| 批次 | 目标 | 交付内容 | 复杂度 |
| --- | --- | --- | --- |
| 第一批 | 阅读操作可靠、位置准确 | 漫画跳页专项核验与修正；小说跳转预览；长图 / 长段落锚点；下载内容保护 | 中，涉及数据兼容 |

不建议把登录系统、社区、排行榜或动画视频作为紧接着的一批工作。它们会增加独立的数据、网络及维护范围；当前阅读操作和下载语义的改进更直接回应已有使用问题。

## 新增回归清单

- 三种漫画方向各自验证滑杆、音量键、首尾页、跨章、缩放手势。
- 小说滑杆预览章节与最终落点一致，跳转后支持返回原阅读位置。
- 长段落 / 长图中途退出、旋转、改字体 / 缩放后恢复内容锚点。
- 在线作品断网时清楚提示；已下载作品在无网和清理临时缓存后仍可读。
- 下载在 50% 时断网、切后台、进程结束、重启设备后，恢复行为与页面文案一致。
- 搜索、详情、正文、图片四阶段分别注入失败，错误显示在对应操作处，保留已完成内容。
- 320 / 360dp、系统大字体、横屏、TalkBack 检查，不让标题、底栏和面板主要动作被截断。

本轮交付为评审清单，未把这些建议标记为已完成修复。
