- [x] 漫画缩略图、页面书签、双页、裁边、ZIP 文件夹卷章组织、作品独立设置。
- [x] 下载与临时缓存分离；暂停继续、排序、新任务 Wi-Fi 策略、验证断点、前台通知与空间预检。
- [x] 漫画区间与未读下载、更新检查；书库/漫库继续阅读、紧凑统计和网格/列表切换。

- [x] 单元测试、独立真机主流程与阅读交互、Release/R8、APK 签名 / 资产 / SHA-256 校验通过；未覆盖项见构建记录。

## 证据边界

所有代码发现需用对应回归验证后再标记完成。漫画源配置完整导入不等于每个外站当前可用。
私有解密和登录/付费/验证码绕过不在实现范围。正式书库不用于回归，不清除或覆盖正式包。
本轮不推送 GitHub 或发布线上 Release。

上述勾选表示功能已实现，并覆盖对应单元或主流程回归；不表示每个交互和系统条件都已真机穷举。最终产物、日志、测试清单及未覆盖项见 `mobile-reader/BUILD-1.8.0.md`。
